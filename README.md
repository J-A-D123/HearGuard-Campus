# HearGuard Campus｜声护校园

## 一、作品简介

HearGuard Campus 是一款校园安全聆听健康教育与交互式数据可视化平台。

作品结合校园问卷调查、公开研究资料及 WHO–ITU 安全聆听参考框架，帮助用户了解聆听习惯、探索声音暴露关系，并获得个性化行为建议。

## 二、主要功能

1. 校园安全聆听数据可视化
2. 个人听音行为画像
3. 声音暴露模拟器
4. 个性化安全聆听建议
5. 七天安全聆听行动计划
6. 聆听行为改善对比
7. 交互式声音暴露图谱
8. 研究方法与数据来源

## 三、运行环境

- Python 3.10及以上兼容版本
- Streamlit
- Pandas
- NumPy
- Plotly
- OpenPyXL
- 支持 Chrome、Safari、Edge 等现代浏览器

## 四、本地运行

解压项目后，打开终端并进入项目目录。

安装依赖：

```bash
python -m pip install -r requirements.txt
```

启动网站：

```bash
python -m streamlit run 启动声护校园.py
```

按照终端提示，在浏览器中访问本地网址。

## 五、在线体验

https://hearguard-campus.streamlit.app

## 六、数据与科学说明

校园调查共收集126份问卷记录。

公开版使用不包含个人级问卷记录的汇总数据。

网站中的行为评分、声音暴露模拟及行为比较仅用于健康教育，不构成医学诊断或听力损失概率预测。
